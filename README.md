# IYANU PLASTIC STORE - Operations & Management System

Enterprise Plastic Products E-Commerce, Operations Management, Shop Floor Management (SLM), Warehouse Inventory, CRM, and Ticket Resolution System.

Built with React 19, TypeScript, Tailwind CSS, Lucide Icons, and Vite.

## Features
- **Storefront & Catalog**: Customer product browsing, filtering by categories, search, shopping cart, and checkout modal.
- **Shop Floor Management (SLM)**: Real-time work shift scheduling, machine line statuses, technician assignments, production alerts, and metric tracking.
- **Warehouse Inventory**: Real-time stock levels, restock alerts, and supply chain tracking.
- **CRM & Tickets**: Customer issue resolution and ticket dispatching.
- **Sales Analytics**: Revenue metrics, performance trends, and operations reporting.

## Getting Started
1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the development server:
   ```bash
   npm run dev
   ```
